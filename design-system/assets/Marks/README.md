# Marks

The three hypotheses as SVG files, 200 × 200, each in colour, `-ink` (one colour `ink` #11141c for light grounds and print) and `-ivory` (one colour `ivory` #ebe6da for dark grounds).

- `golden-seeds` · A · Golden Seeds: 55 seeds with flower-of-life halos. The halo uses transparency; for stamps and engraving use the bundle's `Mark` with `small` or the ink file at 34 seeds.
- `golden-circles-fade` · C · Golden Circles · Fade, the current default.
- `fibonacci-swirl` · D · Fibonacci Swirl.

Use the files where the bundle cannot run (documents, email, print). Never trace, redraw or recolour them.

`mark.svg` is the colour mark the landing page uses today (top bar, footer, favicon); it is copied from `site/assets/mark.svg`. Use it as the default mark in apps.

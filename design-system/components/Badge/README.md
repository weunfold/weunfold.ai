# Badge

The Open Intelligence pill. Any project, company or person can carry it in a README, on a site, in a deck or in a footer.

- Provide `width` (default 340 px; 170 px in a footer). Below 170 px use the mark alone.
- Dark ground by default; pass `ground: '#ffffff'` and `color: '#11141c'` on light pages, and `ink` for a one-colour badge.
- The words stay OPEN INTELLIGENCE, uppercase; do not translate, rename or add a product name inside the pill.

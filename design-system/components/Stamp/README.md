# Stamp

The Open Intelligence seal: the mark inside two rings, OPEN INTELLIGENCE on top and BUILT TOGETHER · FOR EVERYONE below.

- Provide `size`; it prints from 24 mm and reads on screen from 84 px (pinned to an avatar).
- Night by default; for day pass `ground: '#ffffff'`, `color: '#11141c'`, `subColor: '#4a4f5e'`. For rubber stamps, engraving and embroidery add `ink: '#11141c'` so everything is one ink.
- Never change the words, the ring weights or the position of the mark.

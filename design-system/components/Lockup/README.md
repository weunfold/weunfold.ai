# Lockup

The mark with the wordmark: `horizontal` (default) or `stacked`.

- Provide `size` (the wordmark size); the mark is drawn at 2.3× it beside the words, 3.2× above them.
- Provide `variant` while the decision is open; `ink` for one colour (`var(--ink)` on white, `var(--ivory)` on dark).
- Open Intelligence is never bigger than the mark or the wordmark; keep the lockup's proportions, never re-space it by hand.

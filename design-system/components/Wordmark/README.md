# Wordmark

“we unfold” in Spectral, “we” upright and “unfold” in italic, with OPEN INTELLIGENCE in IBM Plex Mono below.

- Provide `size` (the wordmark's font size); the tag follows at a fifth of it, never larger.
- Always lowercase; letter spacing −2%; never set the words in another face or weight.
- `tag: false` drops the tag, for places where Open Intelligence already appears.
- Colour follows `text` and `text-muted`; pass `color` and `tagColor` (for example `var(--ink)`) for one-colour print.
